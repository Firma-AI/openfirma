## What it is

OpenFirma is a governed runtime for AI agents. It starts agents with a runtime profile, routes outbound traffic through a local enforcement point, checks protected actions against policy, and records the result.

Four invariants shape the design:

- **Fail-closed** - every error path returns DENY.
- **No network on the hot path** - capability validation and constraint enforcement run fully in-process.
- **Deterministic** - same input plus same policy bundle produces the same decision.
- **Envelope immutability** - `ExecutionEnvelope` is built once and never mutated in place.
