## What it is

OpenFirma is a governed runtime for AI agents. It starts agents with a runtime profile, routes outbound traffic through a [local enforcement point](./concepts/architecture/), checks protected actions against [policy](./concepts/policies/), and records the result in a [signed audit log](./guides/audit-log/).

Four [invariants](./concepts/architecture/#the-four-invariants) shape the design:

- **Fail-closed** - every error path returns DENY.
- **No network on the hot path** - [capability validation](./concepts/capabilities/) and [constraint enforcement](./concepts/policies/) run fully in-process.
- **Deterministic** - same input plus same policy bundle produces the same decision.
- **Envelope immutability** - `ExecutionEnvelope` is built once and never mutated in place.
