# Black-box tests

OpenFirma's black-box suites exercise the compiled CLI through deterministic
commands, real coding agents, and managed VS Code launches.

The canonical suite placement, proof contract, workflow, and commands live in
the [`writing-black-box-tests`](../.skills/writing-black-box-tests/SKILL.md)
skill. Load and follow it before adding or changing CLI, structural-sandbox,
live-agent, or VS Code coverage.
