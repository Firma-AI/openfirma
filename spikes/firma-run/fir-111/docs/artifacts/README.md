# FIR-111 Artifact Bundles

This directory stores durable evidence generated by the FIR-111 Linux spike.

## Canonical Dataset

1. `fir-111-20260511-final/`

## Scope

This bundle is intentionally curated for PR readability:

1. matrix-level summaries (`matrix-summary.md`, `runs.tsv`, kernel probe),
2. per-scenario evidence (`summary.txt`, `results.jsonl`),
3. memo-ready extract (`decision-memo-input.md`).

Per-iteration transient debug logs are intentionally excluded.

Note: Some embedded absolute/relative paths inside raw captured files
(`summary.txt`, `results.jsonl`) reflect the original execution environment
before repository cleanup/restructure. They are preserved as-run evidence.
