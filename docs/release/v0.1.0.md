# OpenFirma v0.1.0

Released on 2026-05-25

First public release of OpenFirma — a runtime enforcement boundary that sits
between your AI agents and the outside world. Every outbound call an agent makes
passes through a local Sidecar that evaluates Cedar policies you own, locally,
before the call executes. On ALLOW the call proceeds and credentials are injected
just-in-time; on DENY the call is blocked and a signed audit event is written.

## Highlights

- **Per-call enforcement.** Every outbound call is normalized, classified into an
  action class, and checked against your Cedar policy before it runs.
- **Mini Authority + Sidecar architecture.** The Authority issues capability
  tokens (PASETO v4) and streams policy bundles and revocations to connected
  Sidecars; the Sidecar enforces locally next to each agent process. One Authority
  can govern many agents concurrently.
- **Cedar policies, hot-reloaded.** Policy files under `.firma/policies/` are
  watched on disk and pushed to connected Sidecars within ~30s — no restart.
- **Policy packs.** Postures (`strict`, `dev`, `dev-with-delete-watch`) plus
  service mappings (`anthropic`, `openai`, `github`, `gmail`, `stripe`, `npm`,
  `pypi`, `cargo`).
- **JIT credentials.** Credentials are issued per call on ALLOW; the agent never
  holds raw tokens.
- **Signed audit trail.** Every decision emits an ECDSA-signed execution event
  with the exact envelope the policy evaluated. Events carry a per-run
  `sandbox_id` for filtering in `firma monitor`.
- **Flexible operating models.** Zero-config `firma run -- <agent>`, persistent
  local daemons (`firma sidecar start`), a shared team Authority, and standalone
  proxy mode via `HTTP_PROXY` / `HTTPS_PROXY`.
- **Cross-platform.** Linux, macOS, and Windows/WSL2, with `install.sh` and
  `install.ps1` installers.

## Installation

For v0.1.0 the supported install path is **build from source** (requires
Rust 1.88+ and `protoc`):

```sh
git clone https://github.com/firma-ai/openfirma
cd openfirma
cargo build --release
cargo install --path crates/firma
```

Quickstart:

```sh
firma run -- claude      # enforce a single agent session
firma monitor            # watch decisions live (see Known issues)
```

> Prebuilt binaries for Linux, macOS, and Windows are attached to this release
> (and fetched by `curl -sSf https://install.openfirma.ai | sh`), but they are
> **not code-signed** — see Known issues. **macOS Homebrew** support and
> code-signed binaries are coming in **v0.1.1**.

## Known issues

- **`firma monitor` and `firma doctor`** have a known bug in this release. The
  issue has already been identified and a fix is scheduled for **v0.1.1**. Core
  enforcement — `firma run`, the Sidecar, the Authority, policy evaluation, and
  the signed audit trail — is unaffected.
- **Prebuilt binaries are not code-signed.** On macOS, Gatekeeper warns that the
  developer cannot be verified (open via right-click → Open, or System Settings →
  Privacy & Security → "Open Anyway"); on Windows, SmartScreen warns ("More info"
  → "Run anyway"). Building from source avoids this. Code signing is planned for
  **v0.1.1**.
- **macOS Homebrew** install is not yet available; use build-from-source or the
  install script until **v0.1.1**.
